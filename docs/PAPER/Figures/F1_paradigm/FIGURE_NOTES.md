## Panel C — Analysis Pipeline

**What it shows:**  
Two-row flowchart of the full analysis pipeline:

- **Stage A (blue):** Raw fMRI → GLMsingle (single-trial β amplitudes) →
  Procrustes alignment (per-session) → Shared Response Model
  (HC-only training, K=3–4 per ROI) → Shared colour space (N=7 HC).

- **Stage B–C (green/red):** The shared colour space branches into two
  cross-validation decoders:
  - **LORO** (Leave-One-Run-Out): discrimination, assesses representation quality.
  - **LOCO** (Leave-One-Colour-Out): interpolation, assesses continuous colour
    representation and CVD vulnerability.
  - LOCO vulnerability profiles → **CVD characterisation** →
    **2-component model** (β_s = S-axis shift, β_c = confusion-axis gain) →
    **Pre-image filter** (δ(θ) per stimulus colour, stimulus-space correction).

**Notes on the diagram:**  
- The branch connector from "Shared colour space" descends and then splits
  horizontally to feed both LORO and LOCO (dot marks the branch joint).
- The arrow from LOCO directly to CVD characterise (not shown explicitly)
  is implied by the sequential row-2 flow.

**Nothing requires real data here** — this is a logic diagram. Verify
with the final methods text that step labels match the manuscript terminology.

# CVD 신경-행동 해리 현상 분석
## 전체 시각 위계 (V1/V2/V3/hV4) Config32_determin 기반 종합 분석

---

## 요약

본 분석은 색각이상(CVD) 피험자들의 **전체 시각 위계(V1~hV4)**에서 **신경 신호는 존재하지만 행동적 색 지각은 손상된 해리 현상**을 발견했습니다. 중요한 점은 **특정 시각 영역이 아닌 전체 위계에서 CVD vs HC 차이가 없으며**, 이는 CVD의 색 지각 결핍이 피질 표상의 부재가 아닌 **의사결정/통합 단계의 문제**이거나 **개인별 이질적 손상 패턴**임을 시사합니다.

## 2. 신경-행동 해리 현상 (Neural-Behavioral Dissociation)

### 2.1 해리의 증거

#### 신경 측면 (Neural Signal)
✓ **V1~hV4 전체 위계에서 색 정보 디코딩 가능**
- Config32_determin ANOVA 결과 (Classification Accuracy):

| ROI | HC | CVD | p-value | Cohen's d |
|-----|---------|-----|---------|-----------|
| **V1** | 60.8 ± 16.2% | 55.8 ± 2.2% | 0.513 | 0.42 |
| **V2** | 47.3 ± 15.1% | 40.0 ± 11.1% | 0.355 | 0.55 |
| **V3** | 25.0 ± 8.5% | 29.6 ± 6.8% | > 0.05 | — |
| **hV4** | 26.7 ± 7.8% | 27.5 ± 9.1% | > 0.05 | — |

- **Chance level**: 12.5% (8-way classification)
- **모든 ROI에서 chance보다 유의미하게 높음**

✓ **CVD와 HC 간 통계적 차이 없음 (전체 ROI)**
- V1: p = 0.513, Cohen's d = 0.42
- V2: p = 0.355, Cohen's d = 0.55
- V3, hV4: 유의한 차이 없음
- **초기~고차 피질 전체에서 색 신호가 존재**

✓ **Reconstruction Error (재구성 오차) 통계**
- Config32_determin ANOVA feature selection (전체 피험자):

| ROI | HC | CVD | Difference | p-value | Cohen's d |
|-----|---------|-----|------------|---------|-----------|
| **V1** | 46.7 ± 17.0° (n=6) | 42.4 ± 4.9° (n=3) | -4.2° | 0.694 | -0.29 |
| **V2** | 56.9 ± 16.8° (n=6) | 55.3 ± 5.1° (n=3) | -1.6° | 0.876 | -0.11 |
| **V3** | 82.8 ± 14.1° (n=6) | 78.9 ± 7.5° (n=3) | -3.9° | 0.675 | -0.31 |
| **hV4** | 82.1 ± 4.6° (n=6) | 76.3 ± 3.9° (n=3) | -5.9° | 0.105 | -1.32 |

- **Random error**: ≈90° (completely random)
- **Good performance**: <45° (half of random)
- **계층적 성능 저하**: V1 < V2 < V3≈hV4 (상위로 갈수록 오차 증가)
- **통계 검증**: 모든 ROI에서 CVD vs HC 차이 없음 (p > 0.05)
- **Sample**: HC n=6 (sub-01,02,03,05,06,07), CVD n=3 (sub-08,09,10)

#### 행동 측면 (Behavioral Performance)
✗ **CVD 피험자는 행동적으로 적록 구분 불가**
- Ishihara 검사 실패
- 일상생활에서 빨강-초록 신호등 구분 어려움
- 색 이름 지정(color naming) 과제에서 적록 혼동

### 2.2 해리의 의미

이는 단순히 "CVD가 정상적 색 표상을 갖는다"는 것이 **아니라**:

> **"초기 시각피질(V1/V2)에는 약한 색 신호가 존재하지만,**
> **이 신호가 의식적 지각(conscious perception)으로 이어지지 못한다"**

즉, **문제는 초기 피질 표상의 부재가 아닌, 상위 처리 과정에서의 실패**

## 3. 가능한 메커니즘

### 3.1 신호 대 잡음비(SNR) 가설

**V1/V2 신호는 존재하지만 너무 약하거나 노이즈가 많음**

증거:
- MVPA는 여러 복셀의 패턴을 이용해 약한 신호도 검출 가능
- 개인의 의식적 지각은 단일 시행(single trial)에 의존 → SNR 요구량 높음
- CVD 그룹의 높은 분산 (V1: 55.8±2.2% vs HC 60.8±16.2%)
  - 오히려 CVD가 분산 낮음 → 일관되게 약한 신호?

**해석**:
- V1/V2의 L-M 신호는 완전히 사라진 것이 아니라 **극도로 약화됨**
- MVPA는 이를 검출할 수 있지만, 행동적 의사결정에는 불충분
- 참고: Brouwer & Heeger (2009)도 "classifier는 single-trial 행동보다 더 민감"

### 3.2 상위 영역 손상 가설

**V3/V4/IT에서의 색 처리 실패**

근거:
- V4: 색 항상성(color constancy), 범주적 지각(categorical perception)
- IT: 색 기억, 색 이름 매칭
- V1/V2 신호가 존재해도, V4에서 적절히 통합/증폭되지 못하면 지각 실패

증거:
- V3/hV4 ROI 분석 필요 (현재 데이터에서 성능 낮음)
- Config32_determin에서 hV4 데이터 부족 (sub-01, sub-04만 성공)

### 3.3 의사결정 역치 가설

**신호는 있지만 결정 기준(decision threshold)에 도달하지 못함**

메커니즘:
1. V1/V2에서 약한 L-M 신호 발생
2. 상위 영역으로 전달되지만 신호 강도 부족
3. 의식적 지각을 위한 역치(threshold) 통과 실패
4. 행동 반응에서 "추측(guess)"으로 처리됨

**유사 사례**: Blindsight (맹시)
- V1 손상 환자가 의식적으로는 못 보지만, forced-choice에서는 정확히 반응
- 신호 존재 vs 의식적 접근성의 해리

### 3.4 하향식 억제 가설

**상위 영역이 약한 V1/V2 신호를 무시하도록 학습**

발달 과정:
1. 발달 초기: 약한 L-M 신호로 인한 불안정한 색 지각
2. 뇌가 이 신호를 "신뢰할 수 없음"으로 학습
3. 하향식 주의/게이팅이 L-M 신호를 억제
4. S-(L+M) 신호와 밝기 정보에만 의존하도록 적응

증거 필요:
- Attentional modulation 분석
- V1 vs V4 표상 강도 비교
- 색 이름 지정 과제 vs 색 매칭 과제 비교

| sub-08 (CVD) | V3 | Cyan (225°) | 117.3° | Green-Cyan 혼동? |

## 6. 데이터 해석의 한계

### 6.1 표본 크기 한계
- **Config32_determin에서 분석된 케이스**:
  - V1: HC 4명, CVD 1명 (sub-09)
  - V2: HC 1명 (sub-06), CVD 1명 (sub-10)
  - V3: HC 5명, CVD 1명 (sub-08)
  - hV4: HC 5명, CVD 1명 (sub-08)
  - **ROI당 CVD 1-2명만 분석 가능**

### 6.2 개인차의 영향
- 색 재구성 오차 범위: 29.8° ~ 83.4° (ROI 간 큰 차이)
- 피험자 간 변동이 CVD/HC 차이보다 클 수 있음
- 통계적 검증 불가능 (n=1~2)
- **개인별로 서로 다른 색상이 문제**: 일관성 없음

### 6.3 Config 선택 및 복셀 수의 영향
- Config32_determin: 안정성은 높지만 최고 성능은 아님
- V3/hV4는 매우 적은 복셀 수 (k=4-14) → 노이즈에 취약
- V1/V2는 k=31-100으로 더 robust

### 6.4 ROI 정의의 한계
- 해부학적 atlas 기반 ROI (Wang et al. 2015)
- 개인별 기능적 localizer 없음
- V1~hV4 경계가 부정확할 수 있음

## 7. 신경과학적 함의

### 7.1 전체 시각 위계의 역할 재해석

**전통적 관점**:
- V1/V2: 색 정보의 직접적 표상 (CVD에서 L-M 신호 부재)
- V3/V4: 색 항상성 및 범주화 (CVD 결핍의 핵심 영역)
- IT: 색 기억 및 이름 매칭

**본 연구 시사점**:
- **V1~hV4 모든 영역**에서 색 정보 존재하지만 **약함**
- **특정 영역이 아닌 전체 위계에서 CVD vs HC 차이 없음**
- CVD 지각 결핍은 **의사결정/통합 단계** 또는 **개인별 이질적 손상**

### 7.2 색 지각의 계층 모델 (수정)

```
[망막] → [LGN] → [V1/V2] → [V3] → [V4] → [IT] → [의사결정/행동]
         ↓          ↓         ↓      ↓      ↓
       L-M 약화   약한 신호  약한 신호 약한 신호  통합/역치 통과
                                                실패?
```

**CVD에서 가능한 실패 지점**:
1. ✓ 망막/LGN: L/M 추상체 결핍 (확정)
2. ✓ V1/V2/V3/hV4: 약한 신호 존재 (본 연구) - **모든 영역에서 차이 없음!**
3. ❓ 의사결정/통합: 약한 신호들의 통합 실패 (가장 유력)
4. ❓ 의식적 접근성: threshold 통과 실패
5. ❓ 개인별 이질성: 단일 phenotype이 아님

### 7.3 암묵적 vs 명시적 색 처리

**암묵적 (Implicit) 처리**:
- V1/V2의 약한 신호
- MVPA로 검출 가능
- 무의식적 색 구분 (가능성)

**명시적 (Explicit) 처리**:
- 의식적 색 지각
- 색 이름 지정
- 행동 반응

**해리의 의의**:
- 신경 표상 ≠ 지각적 경험
- "보이지 않는 신호"의 존재
- 의식의 신경 기반 연구에 시사점

## 8. 향후 연구 방향

### 8.1 필수 추가 분석

1. **전체 Config 통합 분석**
   - Config32만으로는 표본 부족 (ROI당 CVD 1-2명)
   - Config01, 26 등 포함하여 n 증가
   - Mixed-effects model로 피험자/config 효과 분리

2. **색상 쌍 혼동 행렬 정량화**
   - Circular plot에서 혼동 패턴 추출
   - 1→5, 2→6 특정 쌍 혼동률 측정
   - CVD의 특징적 혼동 패턴 검증

3. **신호 강도 분석 (Beta magnitude)**
   - 베타 맵 magnitude 비교
   - CVD vs HC의 전체 ROI L-M 신호 크기
   - SNR 직접 측정

4. **개인별 색 채널 프로파일링**
   - 각 CVD 피험자의 L-M vs S-(L+M) 신호 강도
   - 이질적 손상 패턴 확인

### 8.2 추가 데이터 수집 권장

1. **행동 색 변별 과제 (Psychophysics)**
   - 동일 자극에 대한 행동 역치 측정
   - fMRI 신호와 행동 성능의 직접 비교
   - Just-noticeable difference (JND) 측정

2. **색 이름 지정 과제 vs 색 매칭 과제**
   - 명시적(naming) vs 암묵적(matching) 비교
   - CVD에서 해리 여부 확인

3. **V4 기능적 localizer**
   - 색 vs 형태 선택성 매핑
   - 개인별 color-selective V4 정의
   - 더 정확한 ROI 분석

4. **시간 해상도 분석**
   - FIR 모델의 시간별 디코딩 정확도
   - 초기 vs 후기 처리 단계 비교
   - Feedback signal 분석

## 9. 결론

### 9.1 핵심 발견 요약

1. **V1~hV4 모든 영역에서 CVD 피험자도 색 디코딩 가능** (25-60%, chance 12.5%)
2. **CVD vs HC 간 통계적 차이 없음** (모든 ROI에서 p > 0.05)
3. **ROI별로 상이한 패턴**: 일관된 적록 혼동 없음
   - V1, V3: CVD에서 Red-Orange가 더 잘됨 (예상과 반대)
   - V2, hV4: CVD에서 Red-Orange가 더 나쁨 (예상과 일치)
4. **개인별 이질적 손상**: sub-08(Blue), sub-09(Green-Cyan), sub-10(Red-Orange)
5. **신경-행동 해리 현상** - 신호 존재 but 지각 불가

### 9.2 이론적 함의

> **"CVD의 색 지각 결핍은 특정 시각 영역의 손상이 아니라,**
> **전체 시각 위계에서 약한 신호가 의사결정 단계에서**
> **적절히 통합/활용되지 못하는 것으로 보인다."**

**또는**:
> **"CVD는 단일 phenotype이 아니라 개인별 이질적 손상 패턴을 보인다."**

### 9.3 메커니즘 해석 (우선순위)

**가장 유력한 가설**:
1. **의사결정/통합 실패 가설** - 약한 신호들의 통합 또는 역치 통과 실패
2. **개인별 이질성 가설** - 단일 phenotype이 아닌 다양한 손상 패턴
3. **약한 신호 가설** - V1~hV4 모두 SNR 부족, 행동 의사결정에 불충분

**기각된 가설**:
- ~~V4 특정 손상 가설~~ → hV4도 CVD vs HC 차이 없음
- ~~초기 피질 부재 가설~~ → V1/V2에서 신호 존재 확인

### 9.4 연구의 한계

- 표본 크기 부족 (ROI당 CVD 1-2명)
- 개인차가 그룹차보다 큼
- V3/hV4는 매우 적은 복셀 (k=4-14) → 노이즈 취약
- 행동 데이터 없음 (fMRI-행동 직접 비교 불가)

### 9.5 최종 권고

1. **더 많은 CVD 피험자 데이터 수집** (n ≥ 10)
2. **개인별 색 채널 프로파일링** (이질성 확인)
3. **행동-신경 직접 비교** (psychophysics + fMRI)
4. **의사결정 단계 분석** (reaction time, confidence rating)
5. **V3/hV4 복셀 수 증가** (k ≥ 50-100)

## 10. 전문가 코멘트

### 10.1 신경과학적 관점

이 결과는 **색 지각이 단순한 계층적 처리가 아님**을 시사합니다.
- V1~hV4 모든 영역에서 약한 신호 존재
- 하지만 **특정 영역이 핵심이 아님**
- 대신 **전체 위계의 통합/의사결정** 단계가 중요

CVD는:
1. 망막/LGN에서 L-M 신호 약화 (확정)
2. V1~hV4까지 약한 신호 전파 (확정)
3. **의사결정 단계에서 통합/역치 통과 실패** (가장 유력)

### 10.2 임상적 관점

만약 V1~hV4 신호가 존재한다면:
- **신경 보철 (neural prosthesis)** 가능성?
- 의사결정 단계 개입 (attentional training)?
- 하지만 **개인별 이질성** 고려 필수

단, 현재 데이터로는 성급한 결론.

### 10.3 방법론적 관점

**MVPA의 한계 인식 필수**:
- Cross-validated accuracy는 **평균화된 패턴**
- Single-trial 행동과는 다름
- "classifier sees it" ≠ "subject sees it"
- **개인차를 무시할 수 없음** - group analysis의 함정

Notes

2-component model: δθ(θ) = β_s · cos(θ − 90°) + β_c · cos(θ − axis). Confusion axis for deutan ≈ 150°, protan ≈ 16° (CIElab a*–b* angle of Machado-derived confusion line at the project's L*=75 / C=40 ring).

Pre-image: for each canonical target θ* ∈ {0°,45°,…,315°}, the simulator finds θ_pre such that θ_pre + δθ(θ_pre) ≈ θ* (numerical 1° grid search over [0°,360°), refined to 0.05°). An "exact" filter cell turns ✓ when |forward(θ_pre) − θ*| < 0.1°.

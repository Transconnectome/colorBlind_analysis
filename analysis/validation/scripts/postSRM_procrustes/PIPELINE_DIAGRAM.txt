INPUT DATA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📁 Baseline amplitudes: (6 runs, 8 colors, n_voxels) per subject-ROI
   - 9 subjects: sub-01 to sub-06 (HC), sub-08 to sub-10 (CVD)
   - 4 ROIs: V1, V2, V3, hV4
   - Total: 36 combinations

┌───────────────────────────────────────────────────────────────────────────────────┐
│ STEP 1a: PCA DIMENSION REDUCTION ⭐ RECOMMENDED                                    │
│ File: step1a_dimension_reduction_pca.py                                           │
├───────────────────────────────────────────────────────────────────────────────────┤
│ • Run averaging: Split into Odd (1,3,5) and Even (2,4,6) → √3 noise reduction    │
│ • PCA: Fit on 16 patterns (odd+even), transform to 50 components                 │
│ • Geometry preservation: Orthogonal transformation maintains distances            │
│ • Denoising: Low-variance components filtered out                                │
├───────────────────────────────────────────────────────────────────────────────────┤
│ Input:  (6 runs, 8 colors, n_voxels)                                             │
│ Output: odd_pc (8, 50), even_pc (8, 50)                                          │
│ Validation: Cumulative variance >80%, PC1-PC2 circular structure                 │
└───────────────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌───────────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: ITERATIVE PROCRUSTES (HC Template)                                       │
│ File: step2_iterative_procrustes.py                                              │
├───────────────────────────────────────────────────────────────────────────────────┤
│ • Initialize: template = mean(HC odd patterns)                                   │
│ • Iterate: Align each HC → template, update template = mean(aligned)             │
│ • Converge: Typically 3-5 iterations (template_change <0.001)                    │
│ • Project: Apply final template to all subjects (HC + CVD)                       │
├───────────────────────────────────────────────────────────────────────────────────┤
│ HC subjects: sub-01 to sub-06 (n=6, excluding sub-07 outlier)                    │
│ Output: template_hc (8, 50), aligned patterns per subject                        │
│ Validation: Convergence, disparities decrease monotonically                      │
└───────────────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌───────────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: COMPUTE CROSSNOBIS RDMs                                                  │
│ File: step3_compute_rdms_crossnobis.py                                           │
├───────────────────────────────────────────────────────────────────────────────────┤
│ • Stack odd/even as 2 "runs" for cross-validation                                │
│ • Estimate covariance: Ledoit-Wolf shrinkage (optimal for n_features>n_samples) │
│ • Crossnobis: Leave-one-run-out Mahalanobis distance (unbiased)                  │
│ • Reliability: Spearman correlation between odd vs even RDMs                     │
├───────────────────────────────────────────────────────────────────────────────────┤
│ Input:  aligned_odd (8, 50), aligned_even (8, 50)                                │
│ Output: rdm_crossnobis (8, 8), reliability score, shrinkage λ                    │
│ Validation: Reliability >0.5 (good), >0.7 (excellent), λ: 0.2-0.4 typical       │
└───────────────────────────────────────────────────────────────────────────────────┘
                                        ↓
┌───────────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: GEOMETRIC METRICS                                                        │
│ File: step4_geometric_metrics.py                                                 │
├───────────────────────────────────────────────────────────────────────────────────┤
│ Metrics computed per subject:                                                    │
│ • ISC: Inter-Subject Correlation with group mean (HC consistency)                │
│ • Deviation: Euclidean distance from HC mean (CVD divergence)                    │
│ • Circularity: Perimeter/(2π×radius_gyration) via MDS (color wheel structure)    │
│ • MDS Stress: Embedding quality (<0.15 good fit)                                 │
│                                                                                   │
│ Group statistics:                                                                │
│ • HC vs CVD comparison: t-test, p-value, Cohen's d for each metric              │
├───────────────────────────────────────────────────────────────────────────────────┤
│ Hypotheses:                                                                       │
│ H1: ISC_hc (0.7-0.9) > ISC_cvd (0.4-0.7)                                        │
│ H2: Deviation_cvd > Deviation_hc                                                 │
│ H3: Circularity_hc (0.85-0.95) > Circularity_cvd (0.70-0.90)                    │
│ H4: V2/V3 show maximal HC-CVD differences (color processing ROIs)               │
└───────────────────────────────────────────────────────────────────────────────────┘
                                        ↓

KEY VALIDATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

        ✓ PC1-PC2 shows circular structure (HC)
        ✓ No negative eigenvalues

Step 2: ✓ Convergence in 3-5 iterations
        ✓ Template change <0.001
        ✓ Disparities decrease monotonically

Step 3: ✓ Split-half reliability >0.5 for ≥80% subjects
        ✓ Shrinkage λ: 0.2-0.4
        ✓ RDM symmetric, diagonal ≈ 0

Step 4: ✓ ISC: HC > CVD (p<0.05)
        ✓ Deviation: CVD > HC (p<0.05)
        ✓ MDS stress <0.15

Step 5: ✓ All plots generated
        ✓ PC1-PC2 color wheel visible
        ✓ Significant HC-CVD differences

COMPARISON: PCA vs SRM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌──────────────────┬─────────────────────────┬─────────────────────────────────────┐
│ Feature          │ SRM (previous)          │ Procrustes-PCA (this pipeline)      │
├──────────────────┼─────────────────────────┼─────────────────────────────────────┤
│ Dimensionality   │ k≤8 (severe constraint) │ k=50-100 (captures >80% variance)   │
│ Template         │ Joint HC+CVD            │ HC-only normative                   │
│ Noise handling   │ Minimal                 │ Run averaging + Crossnobis + LDW    │
│ Geometry         │ May distort             │ Proven preserved (B&H 2009)         │
│ RDM reliability  │ 0.03-0.45 (low)         │ Expected >0.5                       │
│ CVD modeling     │ Negative inter-corr     │ Deviation from HC norm              │
│ Interpretation   │ Abstract shared space   │ PC1-PC2 → color wheel               │
└──────────────────┴─────────────────────────┴─────────────────────────────────────┘

Expected Improvements:
• +30-50% RDM reliability (run averaging + Crossnobis + PCA denoising)
• Better HC-CVD separation (normative modeling)
• Interpretable geometry (PC1-PC2 color wheel diagnostic)

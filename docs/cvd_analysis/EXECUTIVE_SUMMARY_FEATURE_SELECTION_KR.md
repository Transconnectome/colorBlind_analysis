## 1. 개요

### 방법별 요약 통계

| 방법 | 총 분석 수 | 성공률 | 평균 분류 정확도 | 평균 재구성 오차 | 평균 특징 수 |

### 핵심 발견

**Feature selection이 성능을 극적으로 향상시킴:**
- **Baseline**: 우연 수준 성능 (12.5% vs 12.5% chance)
- **PCA**: 미미한 개선 (15.1%, 여전히 기능적 임계값 이하)
- **ANOVA/RFE**: **상당한 개선** (32-34%, 우연 수준의 ~2.6배)

**⚠️ RFE의 재구성 데이터 누락** - 모든 값이 `nan°`로 표시됨

## 7. 핵심 발견사항

### 7.1 중요 발견

1. **Feature Selection이 필수** ⚠️
   - Baseline 성능: 12.5% (우연 수준)
   - ANOVA/RFE 성능: 32-34% (2.6배 향상)
   - **Feature selection 없이는 파이프라인이 작동하지 않음**

2. **최소 전처리가 최선** 🎯
   - Config01 (전처리 없음): 43.5% 분류, 59.1° 재구성
   - Config16 (과도한 전처리): 16.2% 분류, 83.7° 재구성
   - **스무딩과 high-pass 필터링이 성능 저하**

3. **V1/V2가 색상 디코딩 주도** 🧠
   - V1: 43.4% 분류, 55.9° 재구성
   - V2: 38.4% 분류, 61.9° 재구성
   - V3/hV4: ~22% 분류, ~80° 재구성
   - **예상 밖: 초기 시각 영역이 더 강한 색상 신호 보임**

4. **CVD가 온전한 색상 처리 보임** 🔬
   - Non-CVD: 33.2% ± 17.1%
   - CVD: 31.7% ± 16.1%
   - **유의미한 차이 없음 (p = 0.82)**
   - CVD 피험자가 보상적 신경 메커니즘을 가질 수 있음

5. **개인 변동성이 큼** 📊
   - 최고 피험자 (sub-06): 57.3% 평균, 83.3% 최고
   - 최저 피험자 (sub-01): 20.8% 평균
   - **피험자 차이가 방법 차이를 초과**

### 7.2 방법론적 통찰

#### 효과적인 것

✅ **ANOVA-F feature selection** (k=50-100 특징)
✅ **RFE feature selection** (k=50-100 특징)
✅ **최소 전처리** (config01/config32)
✅ **V1 및 V2 ROI**
✅ **안정성을 위한 표준화** (config32: 100% 성공률)

#### 효과 없는 것

❌ **Feature selection 없음** (baseline: 12.5%)
❌ **과도한 공간 스무딩** (6mm: 16-28% 정확도)
❌ **High-pass 필터링** (0.01 Hz가 신호 저하)
❌ **PCA만 사용** (15% 정확도, 불충분)
❌ **V3/hV4 ROI** (일관성 없고 낮은 성능)

### 7.3 최적 설정

종합 분석 기반:

**권장 설정:**
- **전처리**: config32 (스무딩 없음, 표준화, 기본 confounds)
- **Feature Selection**: k=50-100 특징의 ANOVA-F
- **ROI**: V1 또는 V2
- **예상 성능**: 35-45% 분류, 60-70° 재구성

**대안 (최고 정확도):**
- **전처리**: config01 (최소 전처리)
- **Feature Selection**: k=50-100의 RFE 또는 ANOVA-F
- **ROI**: V1
- **예상 성능**: 40-50% 분류, 55-65° 재구성

## 결론

이 종합적인 feature selection 분석은 **ANOVA/RFE feature selection이 fMRI 데이터에서 성공적인 색상 디코딩에 필수적**임을 보여줍니다. Feature selection 없는 baseline 파이프라인은 우연 수준에서 수행되는 반면, ANOVA/RFE는 2.6배 향상을 달성합니다.

**핵심 요점**:

1. ✅ **Feature selection이 효과적** - ANOVA/RFE가 우연 이상 디코딩 가능
2. ✅ **최소 전처리가 최적** - 과도한 스무딩과 high-pass 필터링 피함
3. ✅ **V1/V2가 최고 ROI** - 초기 시각 영역이 가장 강한 색상 신호 보임
4. ✅ **CVD가 온전한 처리 보임** - non-CVD와 유의미한 차이 없음
5. ✅ **개인 변동이 큼** - 피험자 요인이 방법 요인을 지배

**다음 단계**: config32 + ANOVA를 표준 파이프라인으로 구현, V1/V2 ROI에 집중, 그룹 수준 및 비선형 분석 진행.

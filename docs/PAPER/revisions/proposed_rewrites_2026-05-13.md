# 1. Methods §Two-component model class + §Filter — REWRITE

**Replaces methods_v2.tex L235–271** (the LOCO-ρ argmax fit + Machado leak + Brent pre-image).
**L213–233 (model class definition + δθ equation) kept as-is.**

```latex
Within this 2-component model class, the personalized filter for each
CVD subject is the inverse of the fitted transform
$T(\hat{\beta}_s, \hat{\beta}_c)$, computed by:
(i) selecting $(\hat{\beta}_s, \hat{\beta}_c)$ that minimises a
neural-primary composite loss on the hV4 LOCO vulnerability profile, and
(ii) inverting the resulting forward map to obtain a per-hue stimulus
correction.

\paragraph{Selection criterion — HYBRID neural-primary loss.}
For each CVD subject, we score the simulated vulnerability profile
$\mathbf{v}_{\rm sim}(\beta_s, \beta_c)$ against the observed profile
$\mathbf{v}_{\rm obs}$ under
\begin{equation}
  L(\beta_s, \beta_c) = 0.7\,L_{\rm mse}
                       + 0.3\,L_{\rm rdm\text{-}cos}
                       + 2.0\,\mathrm{Tikh}(\beta_s, \beta_c),
  \label{eq:hybrid}
\end{equation}
where $L_{\rm mse} = \tfrac{1}{8}\sum_k(\mathbf{v}_{\rm sim}[k] -
\mathbf{v}_{\rm obs}[k])^2$ captures amplitude (localised distortion
magnitude), $L_{\rm rdm\text{-}cos} = (1 - \cos\langle
{\rm RDM}(\mathbf{v}_{\rm sim}),
{\rm RDM}(\mathbf{v}_{\rm obs})\rangle)/2$ captures scale-invariant
shape consistency, and $\mathrm{Tikh}=\|\beta\|^2/\|\beta_{\max}\|^2$
penalises large filter norms. The two data terms are weighted at
0.7\,:\,0.3 and the regulariser at 2.0; these weights are identical
across subjects (no per-subject tuning) and contain no literature-derived
anchors. The grid is identical to Equation~\ref{eq:2comp}
($26 \times 51 = 1{,}326$ combinations).

Three properties motivate this composite. First, an amplitude term
($L_{\rm mse}$) alone is dominated by HC ceiling variability across
hues; an RDM-cosine term ($L_{\rm rdm\text{-}cos}$) alone is invariant
to mean offset and so cannot resolve the operating point along the
ridge of the $(\beta_s, \beta_c)$ landscape; their weighted sum
constrains both. Second, the Tikhonov term breaks the
near-degeneracy between $\beta_s$ and $\beta_c$ in their joint shift
direction, preferring smaller-norm filters when amplitude and shape
are comparable. Third, the loss contains no behavioural anchor: the
behavioural perception-restoration score (P2a, Sec.\
\ref{sec:methods:behavioral}) is reserved as a held-out evaluation,
preventing target leakage.

\paragraph{Forward simulator.}
$\mathbf{v}_{\rm sim}(\beta_s, \beta_c)$ is generated by passing the
distorted hue set $\{\theta_k + \delta\theta(\theta_k;\beta_s,\beta_c)\}$
through the hV4 ForwardEncoding model that was re-trained on HC data
(\emph{wretrained} simulator). The encoder structure is fixed across
candidate $(\beta_s, \beta_c)$.

\paragraph{Pre-image computation.}
Given the selected $(\hat{\beta}_s, \hat{\beta}_c)$, the correction filter
is the pre-image of $T$. For each displayed hue $\theta_k$, we solve for
the input angle $\tilde{\theta}_k$ such that
$T(\tilde{\theta}_k) = \theta_k$, yielding a per-hue correction
$\delta\theta_k = \tilde{\theta}_k - \theta_k$. A CVD observer viewing
$\tilde{\theta}_k$ thus receives the same hV4 hue representation as a
healthy control observer viewing $\theta_k$.

Pre-images were computed numerically: 1,440 candidate values were
evaluated on the forward map, a sign-change bracket was identified, and
Brent's method was applied for refinement. Bijectivity was confirmed by
verifying $|T(\tilde{\theta}_k) - \theta_k| < 0.001^\circ$ for all 8 hues
and both CVD participants.

\paragraph{Held-out behavioural evaluation (P2a).}
The selected filter was scored against an independent CVD perceptual
matching report \cite{emery2021} that lists, per hue, the perceived
colour name reported by anomalous trichromats. P2a (perception-of-target
accuracy) is the proportion of hues whose filter-corrected percept
matches the reported HC-target percept; we additionally report
``exact / 8'' (per-hue strict match) and $\|\beta\|$ relative to the
P2a-max behavioural target (the $(\beta_s, \beta_c)$ that maximises
P2a; an upper bound, not used in fitting). Because P2a does not enter
Equation~\ref{eq:hybrid}, this evaluation is held-out by construction.

\paragraph{Specificity reporting.}
HC leave-one-out (LOO) norms span $[49.0^\circ, 65.3^\circ]$ (mean
$54.8^\circ$). Both CVD filter norms ($43.1^\circ$, $32.3^\circ$) fall
below this HC band. We report this proximity \emph{descriptively only};
formal specificity claims are precluded by an HC label-permutation
false-positive rate of 100\% under the same selection rule
(Supplementary Materials, baseline-$\rho$ regression-to-mean confound).
```

```latex
% ──────────────────────────────────────────────────────────────────────────────
\subsection{A unified neural-primary 2-component filter recovers per-subject
  distortion at hV4 and aligns with cone-physiology}
\label{sec:results:filter}
% ──────────────────────────────────────────────────────────────────────────────

To recover a stimulus-space correction for each CVD subject, we fit the
2-component model class ($\beta_s$ S-cone retinal shift; $\beta_c$
confusion-axis cortical rotation; Sec.~\ref{sec:methods:twocomp},
Eq.~\ref{eq:2comp}) under a single composite loss
(Eq.~\ref{eq:hybrid}: $0.7\,L_{\rm mse} + 0.3\,L_{\rm rdm\text{-}cos} +
2.0\,\mathrm{Tikh}$). The same loss and the same weights were used for
both subjects; no literature-derived constants entered the fitting.

\paragraph{Subject-specific argmin and held-out behavioural concordance.}
The HYBRID loss yielded distinct argmin solutions for the two CVD
subjects (Figure~\ref{fig:filter}A--B; landscapes in
Figure~\ref{fig:filter}C):
sub-08 (deutan, confusion axis $150^\circ$): $(\hat{\beta}_s,
\hat{\beta}_c) = (16^\circ, +40^\circ)$, $\|\beta\| = 43.1^\circ$;
sub-09 (protan, confusion axis $16^\circ$):
$(12^\circ, -30^\circ)$, $\|\beta\| = 32.3^\circ$.
Against the held-out CVD perceptual matching report
\cite{emery2021}, the corresponding pre-image filters
(Figure~\ref{fig:preimage}) yielded perception-of-target accuracy
P2a $= 0.538$ for sub-08 and P2a $= 0.738$ for sub-09, with three of
eight hues exactly matching the HC-target percept in both subjects.
The subject-specific behavioural-target $(\beta_s, \beta_c)$ that
maximises P2a (used only for reference, not fitting) lies at
$(26^\circ, +34^\circ)$ for sub-08 and $(24^\circ, -20^\circ)$ for
sub-09 (P2a-max $= 0.875$ and $0.950$ respectively); the HYBRID
argmins are $11.7^\circ$ and $18.4^\circ$ from these behavioural
optima in the $(\beta_s, \beta_c)$ plane. Sub-09's higher P2a despite
a larger distance to P2a-max reflects asymmetric weighting in the
P2a-max landscape, not a closer fit; sub-09 is reported as a
proof-of-concept consistent with its single-case status and the
exploratory framing of Sec.~\ref{sec:results:participants}.

\paragraph{Cone-physiology alignment as supporting evidence.}
The two argmin solutions show subject-appropriate $\beta_c$ signs
without any literature-derived prior in the loss
(Eq.~\ref{eq:hybrid}): sub-08 (deutan) $\beta_c = +40^\circ$ (positive
along the deutan confusion axis), sub-09 (protan) $\beta_c = -30^\circ$
(negative along the protan confusion axis). This sign pattern matches
the cone-physiology prediction of \citeA{brettel1997}, where deutan
and protan confusion-axis rotations operate in opposite directions
under the dichromatic anchor convention. The alignment was not
imposed; it emerged from neural data alone. Within the same model
class, the $\beta_s$ values ($16^\circ$ sub-08, $12^\circ$ sub-09)
are within the range of the $21.4^\circ$ S-cone-axis re-weighting
reported by \citeA{emery2021} from behavioural hue scaling in an
independent anomalous-trichromat cohort. We do not claim parameter-
value convergence (the two quantities have different physical units);
we note structural consistency between the recovered $\beta_s$
direction and the prior behavioural cone-axis estimate.

\paragraph{Specificity is descriptive only.}
Both CVD filter norms ($43.1^\circ$, $32.3^\circ$) fall below the HC
leave-one-out range $[49.0^\circ, 65.3^\circ]$ (mean $54.8^\circ$;
n=6 effective). We report this descriptively. Formal specificity
claims are precluded by an HC false-positive rate of 100\% under a
label-permutation null applied to the same composite loss, and by a
baseline-$\rho$ regression-to-mean confound (HC correlation
$-0.894$ between baseline $\rho$ and HC norm; Supplementary
Materials). These limitations were established across thirteen
selection-rule reformulations; no rule within the
voxel-prediction $L_{\rm LOCO}$ measurement family removed them. The
behavioural P2a metric (above) serves as the primary subject-level
evidence; statistical specificity vs.\ HC awaits a larger HC pool
and the Phase-3 two-alternative forced-choice validation
(Sec.~\ref{sec:methods:behavioral}; Figure~\ref{fig:behav} stub).
```

```latex
% ──────────────────────────────────────────────────────────────────────────────
\subsection{Behavioral concordance and filter validation}
\label{sec:methods:behavioral}
% ──────────────────────────────────────────────────────────────────────────────

Two behavioral procedures were used: (i) a same-day color identification
check against the scanner stimulus set, and (ii) [\emph{PENDING — Phase 3}]
a two-alternative forced-choice (2AFC) discrimination protocol with the
personalized filter applied to the display.

\paragraph{8AFC color identification (completed).}
Participants selected the matching hue from eight options identical to
the scanner stimulus set under the same display conditions. This
procedure provides a same-day check of the participant's hue
identification under display conditions and is reported descriptively
as proportion correct per hue.

\paragraph{Held-out perception target (P2a).}
The held-out target used to evaluate filter performance in
Sec.~\ref{sec:results:filter} was constructed from the CVD perceptual
matching report of \citeA{emery2021}, which lists, per hue, the
colour name reported by anomalous trichromats. P2a (perception-of-target
accuracy) is the proportion of hues whose filter-corrected percept matches
the reported HC-target percept; ``exact / 8'' is the strict per-hue match
count.

\paragraph{2AFC discrimination validation [\emph{PENDING — Phase 3}].}
The 2AFC protocol is preregistered to test whether, along hue pairs
identified per participant as LOCO-vulnerable, the personalized
HYBRID filter reduces JND relative to the uncorrected display.
Trial structure, staircase, and stop rules will be reported with the
Phase 3 data; results will appear in Figure~\ref{fig:behav} (currently
a placeholder).
```

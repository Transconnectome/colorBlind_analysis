# Behavioral summary — exp1 (baseline) + exp2 (filters)

**Scope**: JND (8 hue-pair discrimination thresholds) and RSVP-8AFC (color identification).
**Subjects**: HC = sub-01–07 (JND n=7; RSVP n=4: sub-01,03,06,07). CVD = sub-08 (deutan), sub-09 (protan).
**Conditions**: exp1 = no-filter baseline (ses1); exp2 (ses2, **sub-08 & sub-09**) = **window** (deployed macOS Color Filter, subject-tuned intensity, build 26.5.1) and **optimal** (personalized 2-comp pre-image filter).

> Lower JND = better discrimination. z = (value − HC_mean)/HC_sd per pair (effect size). **exp2 now complete for both sub-08 and sub-09.**
> Generated by `analyze_exp2_behavior.py` (own-baseline) + `analyze_exp2_jnd_vs_hc.py` (HC-referenced + Crawford-Howell). Single CVD subject, single run per condition — descriptive.
> **Significance standard (chosen 2026-06-30): Crawford & Howell (1998) single-case-vs-HC t-test** (df = N_HC−1 = 6), NOT a naïve z-test — the latter overtests against N=7 controls. Per-pair CH p-values are in §(1)/(2); the z columns below are the case effect size (value−HC_mean)/HC_sd.

## (1) exp1: CVD − HC difference (the deficit)

**sub-08 (deutan).** The deficit is **localized to 3 pairs** (all on the yellow axis), not global, and all reach Crawford-Howell significance:
- **orange-yellow** (z = +4.2, CH p = 0.008), **yellow-green** (z = +4.3, CH p = 0.007), **yellow-purple** (z = +6.7, CH p = 0.001).
- The remaining 5 pairs sit within ±1.2 z of HC.
- Mean |z| = 2.24, mean signed z = +1.55 (uniformly elevated, never below HC — at baseline the deficit is one-directional: worse discrimination).
- Same locus in 8AFC: accuracy 0.812 vs HC 0.973 and RT 3.72 s vs HC 2.44 s, with errors concentrated in the yellow–green and purple–magenta regions.

**sub-09 (protan).** Essentially HC-equivalent on this paradigm: JND mean 0.097 (HC 0.104), 8AFC 1.000, RT 1.52 s. **No pair reaches Crawford-Howell significance** — the only deviation is **green-blue** (z = +2.4), which is a *trend* under CH (p = 0.070, not p<0.05; a naïve z-test would call it significant at p = 0.018, but that overtests N=7). green-blue is the protan blue–green axis. → sub-09 has little behavioral headroom; its CVD signature is localized to one trend-level pair, neural/subtle rather than a frank behavioral deficit here.

> Implication for Phase 3: sub-08 shows a frank baseline deficit → a filter benefit is testable as **restoration**. sub-09 is already HC-like → its filter test is one of **preservation vs harm**, not restoration.

## (2) exp2: how each filter changes the deficit

### sub-08 (deutan) — restoration; window ≈ optimal

Both filters move sub-08 from a strongly elevated profile (mean |z| 2.24) toward HC (window 0.85, optimal 0.78) and collapse the 8AFC deficit (0.812 → 0.969 for both; RT 3.72 → 2.44 window / 2.08 optimal).

**The 3 baseline-deficit pairs are normalized by both filters:**

| Pair | baseline (z) | window (z) | optimal (z) |
|---|---|---|---|
| orange-yellow | +4.2 | −1.4 | −1.7 |
| yellow-green | +4.3 | −0.2 | +1.5 |
| yellow-purple | +6.7 | −0.7 | +1.4 |

**But neither filter is uniformly HC-faithful** (deviation in *either* direction matters, since the goal is HC-*like* perception, not maximal discriminability):

- Out of HC empirical range (per pair):
  - **baseline**: 3 pairs, all ↑ (deficit) — orange-yellow, yellow-green, yellow-purple.
  - **window**: 1 pair ↑ — green-blue newly mildly worsened (z +1.6).
  - **optimal**: 2 pairs — yellow-green ↑ (z +1.5) and **orange-yellow ↓ over-corrected** (0.046 < HC min 0.064, z −1.7).
- Mean signed z: window −0.25 (slight net over-separation), optimal −0.03 (net-centered on HC).
- Mean |z| (overall closeness to HC): window 0.85 ≈ optimal 0.78 — **tied**.

**Window vs optimal cannot be ranked from this data:**
1. Underpowered — single subject, single run, 8 pairs (Wilcoxon optimal vs window p = 0.84).
2. **Pipeline confound** (per Path A decision): window = OS-level post-display transform, optimal = PsychoPy direct render. A JND win or tie is therefore not interpretable as personalization. The personalization-specific test lives in the cross-swap (own vs other filter) and fMRI prongs.
3. The two filters fail on *different* pairs (window: green-blue ↑; optimal: orange-yellow ↓ over-correction) — distinct error modes, not a clean ordering.

**Robust, reportable claim**: both the deployed macOS filter and the personalized filter restore sub-08's discrimination and identification to near-HC levels, eliminating the catastrophic yellow–green / purple–magenta confusions. The optimal-vs-window comparison is reserved for the mechanism-specific (pipeline-robust) analyses.

### sub-09 (protan) — preservation vs harm; optimal ≫ window

sub-09's baseline is already HC-like, so the contrast is not restoration but whether a filter *preserves* HC-like perception or *degrades* it:

- **Optimal preserves**: mean |z| 0.93 ≈ baseline 0.90; 8AFC 0.984 ≈ baseline 1.000. green-blue (the one baseline trend pair) is normalized to HC (z +2.4 → +0.9, CH p = 0.444).
- **Window degrades**: mean |z| jumps to 1.78 (mean signed z +1.09 — net over-separation), 8AFC drops 1.000 → 0.859. It does **not** help green-blue (worsens it: z +2.4 → +5.1, CH p = 0.003) and **introduces a new deficit at cyan-magenta** (z −0.3 → +6.2, CH p = 0.001) where baseline was normal.

| Pair | baseline (z) | window (z) | optimal (z) | note |
|---|---|---|---|---|
| green-blue | +2.4 (trend) | **+5.1 (CH p=.003)** | +0.9 | optimal → HC; window doubles deficit |
| cyan-magenta | −0.3 | **+6.2 (CH p=.001)** | −1.5 | window-*induced* deficit; optimal keeps normal |

The 8AFC error structure matches: window introduces protan green→cyan (×6) and red→orange (×2) confusions that neither baseline nor optimal show. **Here the deployed macOS filter actively harms an already-good protan observer, while the personalized filter does not** — a direction the pipeline confound cannot explain (a uniform OS post-transform should not selectively create pair-specific deficits on exactly the protan axis).

### Cross-subject synthesis

| | sub-08 (deutan) | sub-09 (protan) |
|---|---|---|
| baseline vs HC | frank deficit (mean \|z\| 2.24; 3 CH-sig pairs; 8AFC 0.81) | HC-like (mean \|z\| 0.90; 0 CH-sig; 8AFC 1.00) |
| Optimal | restores → HC (\|z\| 0.78; 8AFC 0.97) | preserves HC (\|z\| 0.93; 8AFC 0.98) |
| Window | restores → HC (\|z\| 0.85; 8AFC 0.97) | **harms** (\|z\| 1.78; 8AFC 0.86) |

**Unifying claim (both subjects, behavioral)**: the **personalized Optimal filter is at least as HC-like as no-filter and never worse than Window** — it restores the impaired deutan and preserves the already-good protan. The **generic deployed Window filter helps the deutan but harms the protan** (degrading discrimination and identification, creating new protan-axis confusions). This dissociation is the behavioral argument *for personalization*: a one-size-fits-all filter can be net-harmful for some CVD subtypes, whereas the model-derived filter is not. (Optimal-vs-Window remains pipeline-confounded for *mechanism*; the claim here is about *outcome* safety/benefit, which is what a deployed product must guarantee.)

## Caveats

- **Block order (sub-08 ses2, interleaved)**: ① window JND → ② optimal 8AFC → ③ optimal JND → ④ window 8AFC. For JND, window preceded optimal (practice favors optimal, yet tied). For 8AFC, optimal preceded window (so optimal's faster RT is *against* the practice gradient; window-last may carry fatigue). Order is not fully separable in n=1.
- **Block order (sub-09 ses2)**: window (run-1) preceded optimal (run-2) for both JND and 8AFC. Practice/fatigue would therefore *favor optimal* — but note the headline sub-09 result is that **window is worse than baseline** (8AFC 1.00→0.86), which a within-session practice effect cannot produce (baseline is a separate earlier session); and optimal ≈ baseline. So order does not explain the window-harm finding, though it does mean optimal's edge over window is not order-controlled in n=1.
- Baseline = ses1 (separate session) → cross-session practice/learning inflates the baseline→filter gap.
- Window intensity/subtype was subject-tuned → it is a *configured clinical* comparator, not a naive one. "Optimal ≈ window" therefore means "matches a well-configured deployed filter."
- HC normative bands are unstable (JND n=7, right-skewed, bounded at 0); parametric bands flip on high-variance pairs depending on the distributional assumption. The HC empirical range (min–max) + continuous signed z are reported as the assumption-light summary.

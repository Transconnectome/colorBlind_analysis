# OHBM 2026 Abstract Category Recommendation

## 현재 초안 분석

### 연구의 핵심 요소
1. **연구 주제 (Research Topic)**:
   - Color vision deficiency (CVD)에서의 색 지각 신경 표상
   - Visual cortex (V1, V2, V3, hV4)에서의 색 정보 처리
   - Neural-behavioral dissociation in color perception

2. **방법론 (Methodology)**:
   - BOLD fMRI
   - Multivariate pattern analysis (MVPA)
   - Forward encoding model (Brouwer & Heeger 2009)
   - Classification and reconstruction metrics

3. **주요 발견**:
   - CVD와 HC 간 신경 색 디코딩에 유의한 차이 없음
   - 행동적 결핍에도 불구하고 신경 표상은 보존됨

### 🥈 SECONDARY CATEGORY (최우선 추천)

**Parent Category**: **MODELING AND ANALYSIS METHODS**

**Sub-Category**: **Classification and Predictive Modeling**

#### 선정 이유:
✅ **방법론적 기여 강조**
- Forward encoding model 사용 (predictive modeling)

- Leave-one-run-out cross-validation

✅ **Method의 중요성**
- Abstract의 Methods section이 상세함 (2,999 characters)
- ANOVA feature selection, forward encoding 등 methodological details
- Brouwer & Heeger (2009) method를 CVD 연구에 적용

✅ **추가 reviewer pool**
- MVPA/decoding methods 전문가들도 관심

✅ **다양한 청중 확보**
- Visual perception + Methods 두 분야 연구자 모두 관심
- Poster session 배정 시 유연성 확보

- Pattern analysis methods 강조

#### 단점:

- Forward encoding model의 predictive 측면을 덜 강조

---

### Alternative Secondary Category 2

**Parent Category**: **NEUROANATOMY**

**Sub-Category**: **Cerebral Cortex**

#### 장점:
- V1, V2, V3, hV4 등 visual cortex regions 분석
- ROI-based analysis
- Hierarchical processing (V1 < V2 < V3 ≈ hV4)

#### 단점:
- 우리 연구는 anatomy보다 perception과 decoding이 핵심
- Neuroanatomy는 부차적 요소
- Methods 측면이 더 중요

---

### Alternative Secondary Category 3

**Parent Category**: **CLINICAL CONDITIONS OF THE NERVOUS SYSTEM**

**Sub-Category**: **Neurodevelopmental / Early Life**

#### 장점:
- CVD는 genetic/developmental condition
- Clinical population 연구

#### 단점:
- ❌ **추천하지 않음**: 우리 연구는 basic neuroscience focus
- Clinical intervention이나 diagnosis가 아님
- Neural mechanisms of perception이 주제
- CVD는 model/population이지 clinical endpoint가 아님

- **Primary**: 무엇을 연구했는가 (What) → Visual color perception
- **Secondary**: 어떻게 연구했는가 (How) → Classification and predictive modeling

- 이유: Basic neuroscience 연구이지 clinical study가 아님

### ❌ GENETICS → Neurogenetic Syndromes
- 이유: CVD의 genetic basis를 언급하긴 하지만
- Genetics가 연구의 핵심이 아님

- 이유: Developmental aspect는 다루지 않음

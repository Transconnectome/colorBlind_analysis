## 1. 전반적 구조: 색상에서 뇌 반응까지

### 핵심 아이디어

> **"어떤 색을 보여주면 뇌가 어떻게 반응할지 예측하고 싶다"**

### 전체 흐름도

```
물리적 색상       채널 반응         공통 공간         뇌 활성 패턴
(0-360도)    →   (6개 채널)    →   (SRM 정렬)   →   (복셀 반응)
    θ                C(θ)             W_enc             ŷ(θ)

예시:
빨간색(0°)   →   [1.0, 0.3, 0, 0, 0, 0.1]   →   (SRM 변환)   →   [v1, v2, ..., vk]
                 ↑ 각 채널이 얼마나 반응하는지
```

### 비유로 이해하기

**마치 음악 녹음 과정과 비슷합니다:**

1. **물리적 색상 (θ)** = 연주자가 내는 실제 소리
   - 빨강, 주황, 노랑... 360° 색 공간

2. **채널 반응 C(θ)** = 마이크 6개가 각자 소리를 감지
   - 마이크 1: 빨강 계열에 민감
   - 마이크 2: 주황-노랑 계열에 민감
   - ...
   - 각 마이크가 "내가 얼마나 반응하는가?" 신호 생성

3. **SRM 공통 공간** = 다른 녹음실에서 녹음해도 같은 기준으로 맞추기
   - 사람마다 뇌 구조가 다름 (마치 녹음실마다 음향이 다름)
   - SRM으로 "공통 기준"으로 정렬
   - 7명의 정상인 데이터로 기준 공간 만듦

4. **뇌 활성 패턴 ŷ(θ)** = 최종 녹음 파일
   - "이 색을 보면 뇌의 이 부분들이 이렇게 반응할 것"

### 왜 이렇게 하나요?

**문제**:
- 색맹자에게 어떤 색을 보여줘야 정상인처럼 인식할까?
- 측정한 색은 8개뿐 (0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°)
- 하지만 모니터는 360° 전체 색을 표현 가능!

**해결**:
- **예측 모델**을 만들어서 측정 안 한 색(예: 22.5°, 30°)도 "뇌가 이렇게 반응할 것"이라고 예측
- 색맹자에게 보정 필터 적용 시 360° 전체에 대해 최적화 가능!

### 2.1 원본 뇌 활성 데이터 (복셀 데이터)

→ **사람마다 뇌 구조가 다르니까 복셀 개수도 다름!**

### 2.2 채널 반응 데이터

**차원**: `(n_angles, n_channels)`

**예시 - 8개 색에 대한 채널 반응**:
```python
shape: (8, 6)

8 = 색 개수 (0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°)
6 = 채널 개수 (0°, 60°, 120°, 180°, 240°, 300° 중심)

실제 값 예시 (빨간색 0°를 보여줬을 때):
[
  [1.00, 0.25, 0.00, 0.00, 0.00, 0.25],  ← 빨강(0°): 채널1이 가장 강하게 반응
  [0.75, 0.75, 0.25, 0.00, 0.00, 0.00],  ← 주황(45°): 채널1,2가 함께 반응
  [0.25, 1.00, 0.75, 0.00, 0.00, 0.00],  ← 노랑(90°): 채널2가 가장 강하게 반응
  ...
]
```

**비유**:
- 6개의 "색 감지기"가 있다고 상상
- 각 감지기는 특정 색 범위에 민감
- 어떤 색을 보면 감지기들이 "나는 이 정도 반응!"이라고 신호 보냄

**채널 반응 함수 (수식)**:
```python
채널_i의 반응 = cos²((색_각도 - 채널_중심) / 대역폭)

# 예시: 빨간색(0°)를 보여줬을 때
채널1 (중심 0°):   cos²((0 - 0)/30)   = 1.00  ← 정확히 일치, 최대 반응
채널2 (중심 60°):  cos²((0 - 60)/30)  = 0.25  ← 약간 반응
채널3 (중심 120°): cos²((0 - 120)/30) = 0.00  ← 너무 멀어서 반응 없음
```

**왜 6개 채널인가?**
- 360°를 6개로 나누면 60°씩 담당
- 이론적으로 연속적인 색 공간을 잘 표현할 수 있는 최소 개수
- (더 많으면 정확하지만 데이터 부족, 더 적으면 해상도 낮음)

### 2.3 SRM 공통 공간 데이터

**차원**: `(n_runs, n_colors, k)`

**예시 - sub-01의 V1 영역을 SRM 공간으로 변환**:
```python
원본:  (6, 8, 568)  ← 568개 복셀 (사람마다 다름)
↓ SRM 변환
변환: (6, 8, 4)    ← 4차원 공통 공간 (모든 사람이 같은 차원)

6 = 실험 회차
8 = 색 개수
4 = V1에서 선택한 공통 차원 개수 (k)
```

**ROI별 공통 차원 (k 값)**:
| 뇌 영역 | k값 | 의미 |
|---------|-----|------|
| V1      | 4   | V1의 색 정보는 4차원으로 표현 가능 |
| V2      | 4   | V2의 색 정보는 4차원으로 표현 가능 |
| V3      | 3   | V3는 조금 더 단순 (3차원) |
| hV4     | 3   | hV4도 3차원 |

**SRM이 뭔가요?**

**비유 1: 언어 번역기**
- 사람A: "안녕" (한국어)
- 사람B: "Hello" (영어)
- 사람C: "Bonjour" (프랑스어)
- → SRM: 모두 **"인사"**라는 공통 개념으로 변환

**비유 2: 키 맞추기**
- 노래방에서 같은 노래를 부르는데
- 사람마다 목소리 음역대가 다름
- → 키를 맞춰서 "같은 기준"으로 부르게 하기

**실제로는**:
- 7명의 정상인 뇌 데이터를 "공통 기준 공간"으로 정렬
- 568개 복셀 → 4차원으로 압축하면서 핵심 정보만 남김
- 사람마다 다른 복셀 개수 문제 해결!

**수식 (참고용)**:
```
X_i (개인 i의 복셀 데이터, n_voxels_i 차원)
  ↓ 회전 변환 W_i
S (공통 공간, k 차원)

목표: X_i ≈ W_i × S  (모든 사람에 대해)
```

### 2.4 인코더 가중치 (Encoder Weights)

**차원**: `(n_channels, k)`

**예시 - V1 영역의 인코더**:
```python
shape: (6, 4)

6 = 채널 개수
4 = V1 공통 공간 차원

실제 값 예시:
W_enc = [
  [0.82, 0.31, -0.15, 0.08],  ← 채널1이 4개 차원에 미치는 영향
  [0.45, 0.75, 0.22, -0.10],  ← 채널2가 4개 차원에 미치는 영향
  [-0.12, 0.55, 0.68, 0.25],  ← 채널3이 4개 차원에 미치는 영향
  ...
]
```

**의미**:
- "채널 반응"을 "뇌 활성 패턴"으로 변환하는 변환표
- 이 표를 알면 임의의 색에 대한 뇌 반응을 예측 가능!

**학습 방법**:
```python
# 8개 색에 대해
채널 반응 C:     (8, 6)  ← 알고 있음 (계산 가능)
뇌 패턴 Y:       (8, 4)  ← 측정한 데이터

# 최소제곱법으로 W_enc 찾기
W_enc = argmin ||C × W_enc - Y||²
      = (C^T C)^(-1) C^T Y
```

## 3. Decoder 구조 (Forward Encoding Model)

### 3.1 기본 개념

**Forward Encoding = 앞으로 예측**

```
입력: 색상 (예: 22.5°)
  ↓
예측: "이 색을 보면 뇌가 이렇게 반응할 것"
```

**Decoder와의 차이**:
- **Decoder**: 뇌 활성 → 색 추정 (역방향, "뇌가 무슨 색 봤는지 알아맞히기")
- **Encoder (Forward)**: 색 → 뇌 활성 예측 (순방향, "이 색 보면 뇌가 어떻게 반응할지")

### 3.2 단계별 예측 과정

**Step 0: 학습 (8개 색으로 인코더 만들기)**

```python
# 측정한 8개 색에 대해
색 각도: [0°, 45°, 90°, 135°, 180°, 225°, 270°, 315°]

# 1단계: 각 색의 채널 반응 계산
C_8colors = [
  [1.00, 0.25, 0.00, ...],  ← 빨강(0°)
  [0.75, 0.75, 0.25, ...],  ← 주황(45°)
  ...
]  # shape: (8, 6)

# 2단계: 실제 측정한 뇌 활성 패턴 (SRM 공간)
Y_measured = [
  [v1, v2, v3, v4],  ← 빨강을 봤을 때 뇌 반응
  [v1, v2, v3, v4],  ← 주황을 봤을 때 뇌 반응
  ...
]  # shape: (8, 4)

# 3단계: 인코더 학습
# "채널 반응 → 뇌 패턴" 변환표 만들기
W_enc = 최소제곱법(C_8colors, Y_measured)
# shape: (6, 4)
```

---

**Step 1: 새로운 색의 채널 반응 계산**

```python
# 예시: 22.5° (빨강-주황 중간) 색을 예측하고 싶다

θ_new = 22.5  # 도

# 6개 채널의 반응 계산
C_new = [
  cos²((22.5 - 0)/30),    # 채널1 (0° 중심)   → 0.93
  cos²((22.5 - 60)/30),   # 채널2 (60° 중심)  → 0.68
  cos²((22.5 - 120)/30),  # 채널3 (120° 중심) → 0.07
  cos²((22.5 - 180)/30),  # 채널4 (180° 중심) → 0.00
  cos²((22.5 - 240)/30),  # 채널5 (240° 중심) → 0.00
  cos²((22.5 - 300)/30),  # 채널6 (300° 중심) → 0.07
]
# C_new shape: (6,)
```

**비유**:
- 6개 온도계가 있는데
- 22.5°C 온도를 재면
- 20°C 온도계는 "거의 최대 반응!"
- 25°C 온도계는 "어느 정도 반응!"
- 50°C 온도계는 "전혀 반응 없음"

---

**Step 2: 인코더로 뇌 활성 예측**

```python
# 인코더 적용
ŷ_new = C_new × W_enc

# 구체적으로:
ŷ_new = [0.93, 0.68, 0.07, 0, 0, 0.07] × [
  [0.82, 0.31, -0.15, 0.08],
  [0.45, 0.75, 0.22, -0.10],
  [-0.12, 0.55, 0.68, 0.25],
  ...
]

# 결과: ŷ_new = [y1, y2, y3, y4]  ← 4차원 예측 뇌 활성
```

**비유**:
- 채널 반응 = 악기들의 소리 크기
- 인코더 = 믹싱 테이블 (각 악기를 얼마나 섞을지)
- 뇌 활성 = 최종 출력 음악

---

**Step 3: 360° 전체 예측**

```python
# 1° 간격으로 360개 각도 예측
for θ in [0°, 1°, 2°, ..., 359°]:
    C(θ) = 채널_반응_계산(θ)     # (6,)
    ŷ(θ) = C(θ) × W_enc          # (4,)

# 결과:
predictions_360 = [
  [y1, y2, y3, y4],  ← 0°일 때 뇌 반응
  [y1, y2, y3, y4],  ← 1°일 때 뇌 반응
  [y1, y2, y3, y4],  ← 2°일 때 뇌 반응
  ...
]  # shape: (360, 4)
```

**핵심**:
- 8개 색만 측정했지만
- 인코더를 사용하면
- 360개 전체 색에 대한 뇌 반응 예측 가능!

### 3.3 구조 요약 (전체 그림)

```
┌─────────────────────────────────────────────────────────────┐
│                     Forward Encoding Model                   │
└─────────────────────────────────────────────────────────────┘

1. 입력: 색 각도 θ (예: 22.5°)
   │
   ▼
2. 채널 반응 계산: C(θ) = [c1, c2, c3, c4, c5, c6]
   │                        ↑ 6개 채널의 반응값
   │
   ▼
3. 인코더 적용: ŷ(θ) = C(θ) × W_enc
   │                      ↑ 학습된 가중치 (6 × 4)
   │
   ▼
4. 출력: 예측 뇌 활성 패턴 [y1, y2, y3, y4]
                          ↑ SRM 공통 공간의 4차원
```

### 3.4 실제 적용: 색맹 필터 최적화

**문제**:
- 색맹자가 파란색(180°)을 봤을 때 뇌 반응이 정상인과 다름
- 어떤 색(θ_display)을 모니터에 보여줘야 정상인처럼 인식할까?

**해결 과정**:

```python
# 목표: 정상인이 파란색(180°) 봤을 때 뇌 반응
θ_original = 180  # 파란색

# 1. 정상인의 파란색 반응 예측 (Forward Encoder 사용!)
C_hc = 채널_반응(180)             # (6,)
ŷ_hc_target = C_hc × W_enc_hc     # (4,) ← 이게 목표!

# 2. 색맹자에게 여러 색을 시도해보기
for θ_test in [0°, 1°, 2°, ..., 359°]:
    C_cvd = 채널_반응(θ_test)
    ŷ_cvd = C_cvd × W_enc_cvd

    # 정상인 목표와 얼마나 비슷한지 계산
    차이 = ||ŷ_cvd - ŷ_hc_target||²

# 3. 차이가 가장 작은 각도를 찾기
θ_display = argmin(차이)

# 결과: "파란색(180°) 대신 200°를 보여주면 정상인처럼 인식!"
```

**비유**:
- 색맹자 = 색안경을 낀 사람
- 필터 최적화 = 어떤 색을 보여줘야 색안경 낀 채로도 정상적으로 보이는지 찾기
- Forward Encoder = "이 색 보여주면 이렇게 보일 것" 계산기

## 4. 검증 방법

### 4.1 직접 검증 (LOCO - Leave-One-Color-Out)

**방법**:
```
8개 색 중 1개를 빼고 학습 → 뺀 색 예측 → 실제와 비교

예시:
- 7개 색으로 학습: 빨강, 주황, 노랑, 초록, 시안, 파랑, 보라
- 마젠타(315°)는 숨김
- 마젠타 예측: "315°일 것"
- 실제 측정: 315°
- 오차: 0° (완벽!)
```

**성공 기준**:
- 평균 오차 < 60° (필수)
- 평균 오차 < 45° (우수)
- 참고: 랜덤 추측 시 오차 = 90°

### 4.2 간접 검증 (품질 지표)

**1. 부드러움 (Smoothness)**
```
인접한 각도의 예측값이 급격히 변하지 않는지

예시:
- 22°일 때 예측: [0.5, 0.3, 0.1, 0.2]
- 23°일 때 예측: [0.51, 0.31, 0.09, 0.19]  ✓ 부드럽게 변함
- 24°일 때 예측: [0.9, -0.5, 0.8, -0.3]   ✗ 급격히 변함 (나쁨)
```

**2. 일관성 (Inter-Encoder Consistency)**
```
7명의 정상인이 각자 인코더를 만들었을 때
같은 색에 대한 예측이 비슷한지

예시:
사람1이 22.5° 예측: [0.5, 0.3, 0.1, 0.2]
사람2가 22.5° 예측: [0.52, 0.28, 0.12, 0.18]  ✓ 비슷함
사람3이 22.5° 예측: [-0.3, 0.9, -0.5, 0.7]   ✗ 너무 다름
```

---

## 5. 핵심 정리

### 데이터 흐름 (한 문장 요약)

> **"8개 색 측정 → 채널 모델 학습 → SRM으로 사람 간 정렬 → 360° 전체 예측"**

### 왜 이게 중요한가?

1. **8개 → 360개 확장**
   - 실험에서는 8개만 측정
   - 모델로 360개 전체 예측

2. **개인화 필터 제작**
   - 색맹자마다 최적 색이 다름
   - 360° 전체에서 최적값 찾기

3. **효율성**
   - 360개 색 모두 실험하려면 시간/비용 막대
   - 모델로 예측하면 즉시 계산

### 제한사항

1. **측정 안 한 색은 정확도 낮을 수 있음**
   - 8개 사이 보간(interpolation)은 가능
   - 하지만 실제 측정해봐야 확실

2. **개인차**
   - 정상인 7명 평균 모델
   - 개인마다 조금씩 다를 수 있음

3. **추가 데이터 필요 가능성**
   - 16개 or 32개 색 측정하면 더 정확
   - 현재는 8개로 일단 시도

## 6. 면담 예상 질문 & 답변

**Q1: 왜 6개 채널인가요?**
> A: 360°를 균등하게 나누면서도 연속성을 유지할 수 있는 최소 개수입니다. Brouwer & Heeger (2009) 논문에서 검증된 방식이고, 더 적으면 해상도가 낮고, 더 많으면 8개 색 데이터로는 학습이 불안정합니다.

**Q2: SRM과 Procrustes의 차이는?**
> A:
> - **Procrustes**: 단순 회전/반사로 2개 데이터 정렬 (pairwise)
> - **SRM**: 여러 사람을 동시에 "공통 공간"으로 변환 (multi-subject)
> - SRM이 차원 축소(568 → 4)도 동시에 하므로 노이즈 제거 효과

**Q3: 측정 안 한 색(예: 22.5°)도 정확할까요?**
> A:
> - **직접 검증은 불가능** (측정 안 했으니)
> - **간접 지표로 평가**: 부드러움, 일관성
> - **제한적 검증**: LOCO로 45° 간격은 검증 가능
> - **향후 계획**: 16개 or 32개 색 측정으로 보강 필요 가능

**Q4: 색맹자 3명만으로 충분한가요?**
> A:
> - **개인차 연구로는 충분**: 같은 유전형인데도 다른 뇌 반응 확인
> - **통계적으로는 부족**: 색맹 그룹 전체 일반화는 어려움
> - **개인화 필터 목적이므로 괜찮음**: 각 색맹자별로 맞춤 필터 제작

**Q5: Forward Encoding vs Decoder의 차이?**
> A:
> - **Forward (우리가 하는 것)**: 색 → 뇌 반응 예측
> - **Decoder**: 뇌 반응 → 색 추정 (분류/회귀)
> - 필터 최적화에는 Forward가 필요 (임의의 색 시뮬레이션)

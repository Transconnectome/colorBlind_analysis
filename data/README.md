# Data explanation

## 2nd experiment
### Behavior
Consists of JND and 8AFC, just as 1st experiment, but they consist of two color adjustment options: 
- Optimal: file with 'optimal' is the result with personalized filter derived in `future_phase_2` for each participant. 
- Window: file with 'window' is the result with default filter in macOS (26.5.1 (25F80)). Intensity and subtype is selected from participant's preference. 

**Actual block order (sub-08, ses2)** — task and filter condition were interleaved, NOT blocked by condition:
1. window JND
2. optimal 8AFC
3. optimal JND
4. window 8AFC

(Note: file suffixes `run1`/`run2` index the run within each task type, not the global temporal order. So for JND, window preceded optimal; for 8AFC, optimal preceded window.)

## 2. The three Result panels (the spine's payoff: exists → invertible → works)

### A — A structured cortical distortion *(it exists)*
- **SRM hue-geometry wheels** (OHBM explainer) with HC / Sub-08·V2 / Sub-09·V1 headers.
- **Disparity-by-ROI** line plot (paper Fig 2B): each CVD exceeds the HC ±1 SD band at a *distinct* ROI (Sub-08 V2 **p=0.040**, Sub-09 V1 **p=0.007**, Crawford–Howell).
- Bullets: discrimination preserved (LORO pooled p=0.668) · interpolation impaired (hV4 only, p=0.044) · distinct ROI per subject.

### B — An individualized, invertible filter *(we can build one)*
- **Loss landscape** over (β_s, β_c) + **inverted-filter swatches** (paper Fig 3).
- **Table 1** (hV4): Sub-08 (+6°, −42°), Sub-09 (+2°, +24°); exact inversion, residual < 0.001°.
- Bullets: structure beats cone-shift (R+C non-invertible at protan severity) · neural term carries what behavior cannot (Sub-09 3/7 → 7/7 folds) · exact 8-hue LUT.

### C — Does the filter work? *(2nd-MRI validation — the SD4H punchline)*
- **NEW figure** `fig_validation.png` (generated by `make_validation_fig.py`), 2 rows × 2 subject columns:
  - **top** hV4 LOCO ρ (neural interpolation geometry → HC); **bottom** mean JND (behavior, lower = better).
  - **Sub-08 filled** with verified exp2 numbers; **Sub-09 hatched placeholder** ("to be collected 2026-06-29") — fills in when the next session is analyzed → N=2.
- **Claim (calibrated): behavioral parity + neural superiority.**
  - Behavioral: filter restores JND to HC level (0.19→0.08; HC 0.10), **on par with the deployed macOS filter** (Wilcoxon p=0.84) — *parity, not superiority*.
  - Neural: **only the model-derived filter** restores hV4 LOCO ρ toward HC (+0.18 ≈ HC 0.21); the macOS filter pushes it *further away* (−0.39). Δ = 3.2 HC-SD, run-separated.
  - **Scope label on the panel**: descriptive proof-of-concept, Sub-08, n=4/condition, no permutation; macOS (OS-level) vs PsychoPy rendering differs.

> **Verified numbers** (from `future_phase3_behavioral_analysis/exp2_neural/results/exp2_hc_likeness_sub-08_native.json`
> + `results/exp2_behavior/sub-08_summary.json`): hV4 LOCO ρ — HC 0.208±0.179; no-filter −0.272; macOS −0.388;
> Optimal +0.179. JND — baseline 0.187 / macOS 0.080 / Optimal 0.080 / HC 0.104; Wilcoxon Opt-vs-Win p=0.844.
> **Endpoint correction (2026-06-28):** primary = **hV4 LOCO + behavioral recovery**; V1 within-condition LOCO ρ
> failed permutation and is not used. SRM/RDM convergent metric disagrees on the no-filter anchor (stimulus-identity
> confound) → exp2 leads with LOCO only.

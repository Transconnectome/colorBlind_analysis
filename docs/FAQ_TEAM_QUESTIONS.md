## Q1: 이거 결과가 뭘 나타내는 거야?

### 간단 답변

**"각 CVD 사람마다 뇌에서 색상을 다르게 표현하고, 그 차이를 측정했다"**

### 상세 설명

우리가 측정한 것:
```
HC 사람들의 평균 뇌 패턴: "정상" 기준선
CVD 각 개인의 뇌 패턴: "왜곡된" 패턴

T = CVD_brain - HC_brain
  = "얼마나, 어떻게 왜곡되었는가"
```

**예시**:
- Sub-08: 빨강을 볼 때 뇌가 정상인과 0.178만큼 다르게 반응
- Sub-09: 빨강을 볼 때 뇌가 정상인과 0.113만큼 다르게 반응
- Sub-10: 빨강을 볼 때 뇌가 정상인과 0.117만큼 다르게 반응

**이 차이(T)를 알면**:
- CVD 사람이 보는 "빨강"을 조금 조정해서
- 뇌가 정상인처럼 반응하게 만들 수 있음
- 이게 "필터"

## Q2: CVD는 정상과는 다르게 각도 돌려도 공통 패턴 추출이 안된다는 건가?

### 간단 답변

**아니요!** 각도 돌리기(Procrustes)는 잘 됩니다.
문제는 **"CVD 3명을 평균내면 신호가 사라진다"**는 것입니다.

### 상세 설명

#### Procrustes는 성공 ✅

**정상인(HC) 그룹 내**:
```
Sub-03의 뇌 패턴: [색상1 → voxel response]
Sub-05의 뇌 패턴: [색상1 → voxel response]
→ 각도 돌려서 정렬 (Procrustes) ✅
→ 평균 냄 → HC super participant ✅
```

**CVD → HC 정렬**:
```
Sub-08(CVD)의 뇌 패턴
→ HC super participant에 각도 맞춤 (Procrustes) ✅
→ 차이 계산 (T) ✅
```

**모두 잘 됨!** Procrustes 자체는 문제 없음.

#### 문제는 "CVD 평균"

**CVD 3명을 평균낼 때**:
```
Sub-08: 빨강이 +10 왜곡
Sub-09: 빨강이 +3 왜곡
Sub-10: 빨강이 -2 왜곡

평균 = (+10 + 3 - 2) / 3 = +3.7

→ 개인 효과(+10, +3, -2)보다 훨씬 작아짐!
→ 통계적으로 유의미하지 않게 됨
```

**실제 결과**:
- Individual T: 0.101 ~ 0.178 (큰 효과)
- Group average T: 0.085 ~ 0.095 (작은 효과)
- Group p-value: 0.526 (유의미하지 않음)

#### 왜 이런 일이?

**각 CVD가 다른 방식으로 왜곡됨**:
- Sub-08: 특정 색상 조합에서 크게 왜곡
- Sub-09: 다른 색상 조합에서 왜곡
- Sub-10: 또 다른 패턴

**평균 내면**:
- 서로 상쇄됨
- 공통 패턴이 아니라 개인별 패턴이기 때문

## Q3: 필터 제작 가능하다는 결과는 뭘 기준으로 뽑은 거고?

### 간단 답변

**Bootstrap 통계 검정 결과, 각 CVD의 T가 "확실히 0이 아니다"라고 판정되었기 때문**

### 상세 설명

#### 기준: Bootstrap 95% Confidence Interval (CI)

**통계 검정 방법**:
```python
# 1. CVD 개인 vs HC 평균의 차이 계산
T_observed = CVD_sub08 - HC_super = 0.178 (V2 기준)

# 2. Bootstrap으로 불확실성 측정
for i in range(1000):
    HC_resampled = resample(HC_subjects)
    T_bootstrap[i] = CVD_sub08 - mean(HC_resampled)

# 3. 95% Confidence Interval 계산
CI = [2.5 percentile, 97.5 percentile]
   = [0.173, 0.200]  # Sub-08, V2

# 4. 판정
if CI_lower > 0:  # 하한이 0보다 크면
    print("✅ 유의미! T는 확실히 0이 아님")
```

#### 결과

**모든 CVD가 CI 하한 > 0**:

| Subject | ROI | T | 95% CI | 하한 > 0? |
|---------|-----|---|--------|-----------|
| Sub-08 | V1 | 0.132 | [**0.132**, 0.163] | ✅ Yes |
| Sub-08 | V2 | 0.178 | [**0.173**, 0.200] | ✅ Yes |
| Sub-09 | V1 | 0.115 | [**0.108**, 0.151] | ✅ Yes |
| Sub-09 | V2 | 0.113 | [**0.112**, 0.146] | ✅ Yes |
| Sub-10 | V1 | 0.101 | [**0.095**, 0.144] | ✅ Yes |
| Sub-10 | V2 | 0.117 | [**0.106**, 0.161] | ✅ Yes |

**의미**:
- **모든 CI가 0을 포함하지 않음**
- 즉, T는 "우연히 0"일 가능성이 5% 미만
- CVD와 HC 차이가 **통계적으로 확실함**

#### 왜 이게 "필터 제작 가능"?

**필터 제작의 전제 조건**:
1. CVD와 HC의 차이(T)가 존재해야 함 ✅
2. T가 측정 오류가 아니라 진짜여야 함 ✅
3. T가 충분히 커서 보정할 가치가 있어야 함 ✅

**우리 결과**:
- ✅ T 존재함 (0.101 ~ 0.178)
- ✅ 통계적으로 유의미 (CI가 0 제외)
- ✅ 충분히 큼 (0.1 정도면 meaningful)

**따라서**:
```
필터 제작 가능 ✅

T를 역으로 계산하면:
T_brain → T_stimulus (색상 공간에서의 보정)
→ 필터 생성
```

## 추가 질문 답변

### Q: 그럼 왜 Group-level은 실패했는데 Individual-level은 성공한 거야?

**비유로 설명**:

**Group-level (평균)**:
```
학생 A: 국어 90점, 수학 50점 (평균 70점)
학생 B: 국어 50점, 수학 90점 (평균 70점)
학생 C: 국어 70점, 수학 70점 (평균 70점)

전체 평균: 70점
→ "특별한 패턴이 없다"고 결론 (틀림!)
```

**Individual-level**:
```
학생 A: 국어 강함 ✅
학생 B: 수학 강함 ✅
학생 C: 균형 잡힘 ✅

→ 각자 명확한 패턴이 있음!
```

**우리 결과**:
```
Sub-08: V2에서 크게 왜곡 (0.178) ✅
Sub-09: 균일하게 왜곡 (0.113-0.115) ✅
Sub-10: V2에서 보정 효과? (0.101→0.117) ✅

평균: 0.095 (작아짐)
→ "CVD 공통 패턴 없다"고 보이지만,
→ 실제로는 각자 뚜렷한 패턴이 있음!
```

### Q: 그럼 필터는 어떻게 만드는 건데?

**3단계 과정**:

#### 1단계: Forward Model (자극 → 뇌)

정상인 데이터로 학습:
```
빨강(RGB) → 뇌 반응 패턴
주황(RGB) → 뇌 반응 패턴
노랑(RGB) → 뇌 반응 패턴
...

학습된 모델 = "정상인은 이 색을 보면 뇌가 이렇게 반응한다"
```

#### 2단계: Inverse Transform (뇌 차이 → 색상 보정)

CVD의 뇌 차이(T)를 역계산:
```
T_brain = "CVD가 빨강 볼 때 뇌가 정상과 0.178 차이남"

역계산:
"뭔 색을 보여줘야 뇌가 정상처럼 반응할까?"
→ T_stimulus = "빨강을 15도 회전시킨 색"

이게 보정값!
```

#### 3단계: 필터 적용

입력 이미지의 색상 조정:
```
원본: 빨강(RGB 255, 0, 0)
↓
필터 적용: 빨강을 15도 회전
↓
보정: 주황빛 빨강(RGB 255, 65, 0)
↓
CVD 사람이 보면: 뇌가 정상인처럼 반응!
```

### Q: 필터가 정말 효과 있을까?

**검증 방법**:

1. **뇌 반응 검증** (우선):
   ```
   필터 적용 전: CVD_brain = HC_brain + T (차이 있음)
   필터 적용 후: CVD_brain ≈ HC_brain (차이 줄어듦)

   측정: 차이 감소율 > 50% → 성공 ✅
   ```

2. **행동 검증** (차후):
   ```
   Ishihara test (색맹 검사판)
   필터 전: 못 봄 ❌
   필터 후: 볼 수 있음? ✅

   색상 분별력 테스트
   필터 전: 낮음
   필터 후: 향상됨?
   ```

3. **주관 평가**:
   ```
   CVD 피험자에게 물어보기
   "이게 더 자연스럽나요?"
   "색 구분이 더 잘 되나요?"
   ```

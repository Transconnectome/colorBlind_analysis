# Generative-AI Schematics for Advisor-Meeting Slides

Generated by image-generation models (GPT-5 Image / nanobanana / Imagen / DALL·E).

Used for **conceptual diagrams** only — pipelines, mechanisms, abstract flows.
**Never** for quantitative results (those go in `../` Python figures).

## Required outputs

| File | Slide | Status | Prompt source |
|---|---|---|---|
| `slide3_model_mechanisms.png` | Slide 3 row 1 | TODO | `presentation/claude_in_ppt_prompts_meeting.md` § Slide 3 § C |
| `slide1_pipeline_inset.png`   | Slide 1 Q1 inset | OPTIONAL | same file § Slide 1 § C |
| `slide3_eval_pipeline.png`    | Slide 3 row 3 alternative | OPTIONAL | same file § Slide 3 § C (supplementary) |

## Generation workflow

1. Open GPT-5 Image (preferred) or alternative.
2. Paste the relevant prompt from `claude_in_ppt_prompts_meeting.md`.
3. Pick the best of 4 candidate generations.
4. Save here under the exact filename above.
5. Insert into the slide via Claude-in-PowerPoint at the indicated absolute path.

## Verification before insert

- [ ] No axis numbers (those belong to Python figures)
- [ ] No photographic CVD test plates / Ishihara renderings
- [ ] No anatomical drawings (eyes, brains)
- [ ] No rainbow-gradient decoration
- [ ] Equations rendered as monospace inside grey rounded boxes
- [ ] Cite Machado 2009 / Brettel 1997 / Emery 2021 in tiny italic at bottom
